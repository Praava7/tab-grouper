🔒 Privacy Policy

Tab Grouper Privacy Policy

A plain-language explanation of how Tab Grouper handles (or, more precisely, does not handle) your data.

Effective date: September 2, 2026  ·  Applies to Tab Grouper v1.2.0 and later

✅
Tab Grouper collects zero personal data. No tab titles, URLs, browsing history, or any other information are ever transmitted off your device. All processing happens entirely inside your browser, in local memory, with nothing leaving your machine.
📋

Overview

Tab Grouper is a browser extension for Google Chrome and Mozilla Firefox that automatically organises your open tabs into named groups based on their domain. It works entirely within your local browser session using only the browser APIs listed below, and it does not communicate with any external server, analytics service, or third-party infrastructure.

This policy describes what browser data the extension accesses, how that data is used, and where it is stored. It applies to Tab Grouper published on the Chrome Web Store and on Mozilla AMO (addons.mozilla.org).

🚫

Data We Do Not Collect

Tab Grouper never collects, stores remotely, or transmits:

  • Tab URLs URLs are read transiently in memory to derive a grouping key (domain) and are immediately discarded. They are never logged or sent anywhere.
  • Tab titles Titles are used only to name tab groups on-screen. They are never stored persistently or transmitted.
  • Browsing history The extension has no access to browser history and does not read previously visited pages.
  • Personal identifiers No names, email addresses, account credentials, or device identifiers are ever accessed or processed.
  • Telemetry & analytics Tab Grouper contains no analytics SDK, crash reporter, A/B testing framework, or telemetry of any kind.
  • Network requests The extension makes no outbound network requests. There is no update-check endpoint, no remote configuration server, and no data-collection backend.
💾

Local Storage

Tab Grouper uses the browser's built-in chrome.storage.sync (with a fallback to chrome.storage.local) exclusively to persist your own configuration choices on-device. The following keys are written:

Key What it stores Transmitted?
autoGroupEnabled Whether automatic tab grouping is switched on (boolean). Never
autoCollapseInactive Whether inactive groups collapse automatically (boolean). Never
minTabThreshold Minimum number of same-domain tabs before a group is created (integer 2–20). Never
excludedDomains Domains the user has chosen to exclude from grouping (array of hostnames you type yourself). Never
groupColors Colour assignment preference for groups ("auto" or a specific palette). Never
tabGroupStash A user-initiated snapshot of open tabs and groups created when you click "Stash Window" in the popup. Stored only in chrome.storage.local (device-local only, never synced). Cleared or overwritten the next time you stash. Never

Local only  All storage entries live exclusively on your device inside the browser's sandboxed extension storage. They are never shared with the extension developer or any third party.

🔑

Permissions & Why They Are Needed

Tab Grouper requests the minimum set of permissions required to perform its core function. No host permissions (<all_urls> or similar) are requested — the extension never reads web page content.

  • tabs Allows the extension to query open tabs (URL, title, window ID, group ID) so it can compute domain-based grouping keys and listen for tab lifecycle events (created, updated, removed, activated). No page content is read.
  • tabGroups Allows the extension to create, update, query, and collapse tab groups in the browser's tab strip. Used exclusively for grouping and accordion-collapse features.
  • storage Allows reading and writing the user's own settings (listed in Section 3) to the browser's local extension storage. No external storage or cloud service is used.
🌐

Third-Party Services

Tab Grouper uses no third-party services. It loads no external scripts, fonts, stylesheets, or images from a CDN or remote server. All assets are bundled within the extension package itself.

The optional Feedback & Suggestions button in the Options page and popup opens a Google Form link in a new browser tab. Clicking that link is entirely voluntary; the form is hosted by Google and governed by Google's Privacy Policy. Tab Grouper itself receives no data from the form and has no access to any submitted responses.

👶

Children's Privacy

Tab Grouper does not collect any data from anyone, including children under 13 (COPPA) or under 16 (GDPR). Because no personal information is ever gathered, there are no age-related data-handling requirements applicable to this extension.

📝

Changes to This Policy

If Tab Grouper's data practices ever change, this document will be updated and the effective date at the top of the page will reflect the revision. Because we collect no data, we do not expect this policy to change materially. Any future version of the extension that adds data collection would require an updated policy, renewed store approval, and explicit user consent disclosures before submission.
